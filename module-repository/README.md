# OKOK Declutter

A Vector / libxposed module that hides selected promotional and floating UI in **OKOK 3.7.63 (version code 255)**.

## Features

- Skips the splash-ad wait while preserving OKOK's original account and destination routing.
- Hides the two home-page promotional banners.
- Hides the check-in gift and chat floating entries.
- Hides the animated body-status guide without removing its edit button.
- Hides the report-page bottom advertising container.

The module only runs in `com.chipsea.btcontrol`, declares no Internet permission, and does not modify health data, accounts, VIP entitlements, or OKOK's official data synchronization.

## Compatibility

Only OKOK **3.7.63 (255)** is supported. The module installs no hooks on other versions.

## Installation

1. Install the APK attached to the release.
2. Enable **OKOK Declutter** in Vector.
3. Select only **OKOK** as its scope.
4. Force-stop and reopen OKOK.
